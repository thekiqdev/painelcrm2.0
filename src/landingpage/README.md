# Landing page

Landing pública (layout do [flowcrm-suite](https://github.com/thekiqdev/flowcrm-suite)) usada como **página inicial** do app.

- **Rota:** `/` (home). A rota `/landingpage` redireciona para `/`.
- **Login:** `/login` (tela de login).
- **Cadastro:** `/register`.
- **Links na landing:** "Entrar" → `/login`, "Começar grátis" / "Criar conta" → `/register`.
- **Estilo:** Tema escuro e variáveis CSS aplicados apenas dentro de `.landing-page`.
